# qlik-answers-green-charts

A styling skill for Qlik Answers. Every chart and KPI the assistant creates uses one solid green (#2ca02c). Swap the hex code for your brand color.

**Example**

User: "Break down sales by region."

Answer: a bar chart with every bar in #2ca02c.

**Tested:** 78 of 78 charts green across bar, line and KPI.
