Every row carries an evidence tag. Do not present an `I` row as documented.

| Tag | Meaning |
|---|---|
| **D** | Stated on a public Qlik page (see `sources.md`) |
| **E** | Seen in the nebula.js source (v7.6.0, October 2026; re-check on a new major version) or in a real qlik-oss migration |
| **I** | Inference from D/E facts; verify in your target host |

Target of the mapping: a nebula visualization (`qae` + `component` + `ext`) built with `nebula build` and packaged with `nebula sense`.

## 1. Module shape and packaging

| Legacy | nebula.js | Tag | Notes |
|---|---|---|---|
| `define([...deps], function (...) { return {...}; })` (AMD) | `export default function supernova(galaxy) { return { qae, ext, component() {} }; }` (ES module) | D | `nebula build` bundles it; `nebula sense` generates the AMD wrapper |
| Hand-written `.qext` | Generated by `nebula sense` from `package.json` + `--meta` | D/E | Adds `"type": "visualization"` and `"supernova": true` |
| Extension id = folder / `.qext` / entry JS base name | Last segment of `package.json` `name` (also the default output folder suffix) | E | Use `--output <name>` so the folder matches; see `compatibility-and-rename.md` |
| `require()` of host libraries (`jquery`, `underscore`) | npm dependency, bundled | D | qlik.dev says Qlik is deprecating these libraries for extensions (no date given); bundle your own |
| `text!`, `css!` loader plugins | `import './x.css'` (supported); templates become JS | E | `nebula build` handles CSS via postcss; LESS is not configured |
| `define(['qlik', ...])` | No equivalent | D | Remove; see sections 4 and 5 |

## 2. Extension object members

| Legacy | nebula.js | Tag | Notes |
|---|---|---|---|
| `initialProperties` | `qae.properties` (`src/object-properties.js`) | D | May be `{ initial, onChange }` [E]. Fold in `defaultValue`s from `definition` |
| `definition` | `ext.definition` (`src/ext.js`) | D | Dimension/measure sections become `data: { uses: 'data' }`; limits move to `qae.data.targets` |
| `support: { snapshot, export, exportData, viewData }` | `ext.support` | D | Values may be functions of the layout [D]. See `snapshots-and-export.md` |
| `paint($element, layout)` | `component()` using `useElement()`, `useLayout()` / `useStaleLayout()`, `useEffect()` | D | `$element[0]` becomes the raw `HTMLElement` |
| Return value of `paint` (Promise) | `usePromise()` for async work; rendering waits for pending promises | E | See `snapshots-and-export.md` |
| `resize($element, layout)` | `useRect()` width/height as `useEffect` dependencies | D/E | `useRect` uses `ResizeObserver`, so `component` re-runs on resize |
| `mounted($element)` | `useEffect(() => {...}, [])` | I | |
| `beforeDestroy()` | cleanup function returned from `useEffect` | I | Also destroy any session object you created |
| `updateData(layout)` | `useEffect(..., [layout])` | I | |
| `importProperties` / `exportProperties` | `qae.importProperties` / `qae.exportProperties` | D | Conversion between chart types |
| `getDropFieldOptions` etc. | none documented | I | Not in the public Extension API reference; check whether it is really used |
| `clearSelectedValues` | none; react to `ObjectSelections` events (`deactivated`, `cleared`) | E | |
| `template` / `controller` (AngularJS) | none | D | Rewrite. See `angularjs-rewrite.md` |
| `qlik.registerExtension` | none | I | Build a normal supernova |

## 3. Property panel (`definition` -> `ext.definition`)

The panel objects carry over almost verbatim (E: sn-network-chart, sn-org-chart). Components such as `string`, `integer`, `number`, `checkbox`, `switch`, `dropdown`, `radiobuttons`, `buttongroup`, `slider`, `range-slider`, `color-picker`, `button`, `link`, `text`, `textarea`, `media`, `list`/`array`, `accordion`, `expandable-items` keep their documented behavior.

| Legacy | nebula.js | Tag |
|---|---|---|
| `dimensions: { uses: 'dimensions', min, max }` | `data: { uses: 'data' }` + `qae.data.targets[].dimensions { min, max }` | D |
| `measures: { uses: 'measures', min, max }` | same, `measures` | D |
| `sorting`, `addons`, `settings` (`uses:`) | unchanged | D |
| Labels that need translation | `galaxy.translator.get(...)` inside `ext(galaxy)` (hooks are not available there) | D |
| Theme colors for defaults | `galaxy.anything.sense?.theme` (guarded; Sense only) | D/E |
| Custom components with an AngularJS `template`/`controller` | Not allowed in this skill: use a built-in component | see `host-isolation.md` |

`ext` and `qae` are evaluated outside `component()`, so no hooks there; use the `galaxy` argument.

| `this.backendApi.getData(pages)` | `useModel().getHyperCubeData(path, pages)` | D |
| `backendApi.eachDataRow(cb)` | iterate `layout.qHyperCube.qDataPages[*].qMatrix` | E |
| `backendApi.getRowCount()` | `layout.qHyperCube.qSize.qcy` | E |
| `backendApi.getDimensionInfos()` / `getMeasureInfos()` | `layout.qHyperCube.qDimensionInfo` / `qMeasureInfo` | E |
| `backendApi.getDataRow(n)` | index into the loaded `qDataPages` | E |
| `backendApi.getReducedData` / `getPivotData` / `getStackData` | `model.getHyperCubeReducedData` / `getHyperCubePivotData` / `getHyperCubeStackData` | I |
| `backendApi.getProperties()` / `setProperties(p)` / `applyPatches(...)` | same-named methods on `useModel()` | D/I |
| `backendApi.selectValues(dim, values, toggle)` (instant) | `model.selectHyperCubeValues(path, dim, values, toggle)` | D |
| `this.selectValues(dim, values, toggle)` (modal, toolbar) | `selections.begin([path])` then `selections.select({ method: 'selectHyperCubeValues', params: [path, dim, values, toggle] })` | D/E |
| `backendApi.selectRange(ranges, orMode)` | `model.rangeSelectHyperCubeValues(...)` | I |
| List objects (`qListObjectDef`): `getData` / `eachDataRow` | `model.getListObjectData('/qListObjectDef', pages)`; layout `qListObject.qDataPages` | D |
| List objects: `selectValues(0, [n], toggle)` | `model.selectListObjectValues('/qListObjectDef', [n], toggle)` (modal: `selections.select({ method: 'selectListObjectValues', params: [path, values, toggle] })`) | D |
| List objects: `search` | `model.searchListObjectFor` / `acceptListObjectSearch` / `abortListObjectSearch` | D |
| `backendApi.clearSelections()` | `selections.clear()` | E |
| `backendApi.hasSelections()` | `selections.isActive()` / `layout.qSelectionInfo.qInSelections` | E |
| `backendApi.isSnapshot()` | `layout.snapshotData` is present | E |
| `backendApi.search` / `acceptSearch` / `abortSearch` | none | I |
| `backendApi.setCacheOptions` | none; page explicitly | I |
| `this.selectionsEnabled`, `layout.selectionMode` | `useInteractionState()` (`select`, `active`); CONFIRM vs QUICK = modal vs instant | D/E |
| `$scope.options.interactionState`, `noInteraction`, `inEditState()`; `useConstraints()` (deprecated) | `useInteractionState()` -> `{ passive, active, select, edit }` | E |

See `selections-and-data.md` for code.

## 5. `qlik` root and `app`

`useApp()` returns the raw engine `Doc`, not the capability `QApp` wrapper. Method names differ.

| Legacy | nebula.js | Tag |
|---|---|---|
| `qlik.currApp(this)` | `useApp()` (raw Doc) | E |
| `app.field(name).selectValues(...)` | `(await app.getField(name)).selectValues(...)` | E |
| `field.selectMatch`, `toggleSelect`, `clearOther`, `selectAll`, `selectPossible`, `selectExcluded`, `selectAlternative`, `lock`, `unlock`, `clear` | engine `Field` methods: `select(qMatch, qSoftLock)`, `toggleSelect(qMatch, qSoftLock)`, `clearAllButThis(qSoftLock)`, `selectAll`, `selectPossible`, `selectExcluded`, `selectAlternative`, `lock`, `unlock`, `clear` (check each signature in the engine reference) | I |
| `app.getObject(id)` to read another object (`getProperties`, `getLayout`, `getChildInfos`), `app.getDimension(id)`, `getMeasure(id)`, `getScript()`, `getAppLayout()` | the same-named raw `Doc` methods (promises; `await model.getLayout()`) | D |
| `app.field(name, stateName)` | `await app.getField(name, stateName)`: keep the state argument | D |
| `app.variable.*` | `app.getVariableByName(...)`, `getVariableById`, `setStringValue` / `setNumValue` on the variable | I |
| `app.createCube(def, cb)` | `app.createSessionObject({ qInfo: { qType }, qHyperCubeDef })` then `getLayout()`; destroy on unmount | E |
| `app.getObject(id)` / `app.visualization.get(id)` | `useEmbed().render({ element, id })` (worked in Qlik Cloud after an initial empty-content period; see `app-and-navigation.md`) or engine calls | E |
| `app.theme.getApplied()` | `useTheme()` | D |
| `app.bookmark.apply/create` | `app.applyBookmark` / `app.createBookmark` | D |
| `app.clearAll/back/forward/lockAll/unlockAll` | same names on the raw Doc | D |
| `app.getAppLayout()` | `useAppLayout()` | D |
| `qlik.navigation.*` | `galaxy.anything.sense.navigation` or `useNavigation()` (experimental when written); Sense only | D |
| `qlik.Promise` | native `Promise` | E |
| `app.variable.getContent` / `setContent` | variable `getLayout()` (`qText`) / `setStringValue`, `setNumValue` | I |
| `app.createTable`, `qlik.table(this)` | hypercube session object, or `layout.qHyperCube.qDataPages`, plus your own render | D/I |
| `app.getSheetList()`, `getAppObjectList()` | session object with `qAppObjectListDef` (see `app-and-navigation.md`); not public engine methods | D/E |
| `app.createDimension/createMeasure/createObject` | same-named engine `Doc` methods (they create persistent app content) | D |
| `qlik.navigation.setMode(EDIT)` | none; drop the feature or keep the legacy extension for it | I |
| `qlik.navigation.getMode()` | `useInteractionState().edit` (true in edit mode, false in analysis mode; verified in Qlik Cloud, Oct 2026) | E |
| `luiDialog`, `luiPopover`, `luiTooltip` | own dialog/overlay inside the element | I |
| `qlik.config`, `app.model` | none; derive from the page URL or the raw Doc | I |
| `qlik.resize()` | `useRect()` | I |
| `qlik.openApp`, `callRepository`, `getExtensionList`, `getAppList`, `sessionApp`, `sessionAppFromApp`, `setOnError`, `getGlobal` | none (the Capability API page lists which are unsupported in Qlik Cloud; check it for the current list) | D |
| QVisualization `exportData/exportImg/exportPdf` | none; documented as unsupported in Qlik Cloud (October 2026) | D |

## 6. Environment

| Legacy | nebula.js | Tag |
|---|---|---|
| `qlik.setDeviceType` / device checks | `useDeviceType()` or `galaxy.deviceType` (typed as a string: log the values your host returns before comparing against one) | D |
| Translations | `useTranslator()` / `galaxy.translator` | D |
| Locale / number formatting | `useAppLayout()` -> `qLocaleInfo` | D |
| Options passed by an embedding host | `useOptions()` | E |
| Keyboard handling | `useKeyboard()` (`enabled`, `active`, `focus`, `blur`); a chart that handled Tab or arrow keys itself in the legacy client needs testing in the Sense page | E |
| `qv-activate` event | `click` / pointer events | E |
| `$element.width()/height()` | `useRect()` | E |

## 7. No replacement

Redesign, drop or document in the report: AngularJS `template`/`controller`/`$scope`, `backendApi` search helpers, QVisualization export calls, client-only `qlik.*` calls, run-time CDN loading, host CSS classes.
